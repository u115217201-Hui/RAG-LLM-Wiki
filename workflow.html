Loop / Graph 工作流程

採用 Karpathy LLM Wiki 三層架構：不可變來源卡 → AI 維護的 Wiki → 使用規格 AGENTS.md。

選主題與教學深度（人類確認）
↓
來源取得／審查：五份論文來源卡 raw/
↓　❌ 不可信 → 返回來源取得
Ingest：摘要、來源代碼、更新概念頁、索引與 log
↓
Query Wiki → 整理十頁教學大綱
↓　❌ 無來源 → 回 Wiki 查詢／補資料
Lint：主張、引文、技術用語與初學者可讀性
↓　❌ 不合格 → 回整理步驟
產生 HTML / CSS / JS 簡報
↓　❌ 測試失敗 → 回程式修正
靜態驗證與人工瀏覽 → GitHub Pages 發布

實際檢查與修正

  • 風險節點：概念整理與檢索來源核對。早期容易將 Faiss 稱作「向量資料庫」，或把 RAG 說成能消除幻覺。
  • 流程調整：將來源與主張檢查移到 Wiki 概念頁完成之後、HTML 生成之前，而非等簡報完成才改。
  • 保留後置檢查：HTML 路徑、十頁結構、鍵盤翻頁、連結；自動檢查只代表靜態通過，不代表瀏覽器人工測試。

以上為本專案製作過程的設計與觀察；不是多次模型執行統計，因此「最常出錯」是本次最主要的風險節點，不是量化頻率。
